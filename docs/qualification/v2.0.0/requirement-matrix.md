# Stable v2.0.0 requirement matrix

Date: 2026-10-08.
Status: Crosswalk of the 121 roadmap entries that were unchecked when this matrix was created; subsequent evidence and checkbox updates are recorded in the linked checkpoints.

pass means the complete requirement has evidence at the level stated, with final-candidate repetitions separate when named.
partial means useful evidence exists but one or more clauses remain unproved.
not_run means no execution evidence exists for the requirement.
environment_dependency means completion requires an approved policy, controlled environment, actual client, runtime, hardware, or external release boundary.

The observed environment is Windows 11 Pro x64 build 10.0.26300, Cheat Engine x64 7.7.1.10828, and .NET runtime 10.0.12.
No row generalizes that environment to another Windows, CE, runtime, target, or client.
